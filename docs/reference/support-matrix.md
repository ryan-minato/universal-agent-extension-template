# Support matrix

Per component and framework, two facts: whether a native file is **generated**, and whether the component is
**verified** to work after a real install. "Generated" is what CI checks; "verified" is what a person has confirmed on
the framework (date in parentheses) or an open [verification item](../guides/verification-items.md). This page is the
one place the matrix lives; `frameworks.md` in the repository holds the facts behind it.
