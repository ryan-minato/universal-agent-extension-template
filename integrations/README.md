# Platform integrations

Everything a single framework needs that the shared core (`plugin.json`, `skills/`, `mcp.json`, `agents/`) cannot
express. One directory per framework; `just generate` reads them and writes the native entry files listed in
`.agents/knowledge/architecture.md`.

| File                                                       | Format                     | Meaning                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<fw>/overrides.yaml`                                      | this template's convention | Fields for that framework's manifest that `plugin.json` has no place for (`displayName`, `suggestedPrompts`, component paths). Public fields that `plugin.json` already carries (`name`, `version`, `description`, `author`, `license`, `homepage`, `repository`, `keywords`) are rejected here: `plugin.json` is their only source. |
| `<fw>/agents/<name>.override.yaml`                         | this template's convention | Framework-specific frontmatter merged over `agents/<name>.md` (shallow merge; `body_prepend` / `body_append` add text around the shared body). Only keys the framework documents are allowed; see `scripts/generate/lib/agents.ts` for the allow lists.                                                                              |
| `claude-code/agents/<name>.md`, `codex/agents/<name>.toml` | the framework's own        | A framework-only agent, copied as is.                                                                                                                                                                                                                                                                                                |
| `<fw>/hooks/hooks.json` + `hooks/scripts/`                 | the framework's own        | Hooks are never translated between frameworks; each has its own implementation.                                                                                                                                                                                                                                                      |
| `claude-code/commands/*.md`                                | Claude Code                | Slash commands. Skills are preferred for new work; a command exists here to show the mechanism.                                                                                                                                                                                                                                      |
| `antigravity/rules/*.md`                                   | Antigravity                | Rules with a `trigger` frontmatter; copied to the root `rules/` directory Antigravity scans.                                                                                                                                                                                                                                         |
| `pi/package.patch.json`, `pi/extensions/`, `pi/prompts/`   | Pi                         | Package metadata the manifest cannot derive, the extension entry, prompt templates.                                                                                                                                                                                                                                                  |

A conversion the generator cannot do faithfully fails with a message naming the field and the fix. It never widens a
permission or drops a tool restriction to make a file valid.
