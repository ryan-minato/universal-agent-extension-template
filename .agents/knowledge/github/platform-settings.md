# GitHub Platform Settings

Read before changing anything on the remote repository, when a merge is blocked for a reason no check explains, or when
a setting below changes. Remote settings are maintainer actions: agents read them back, never change them. The one
exception is the label set, which changes only by applying `.github/labels.yml` as `agent-authority.md` allows.

Repository: `ryan-minato/universal-agent-extension-template` · owner: personal account · visibility: public · plan: Free
(rulesets, secret scanning, push protection, CodeQL, private vulnerability reporting, and Pages are available to public
repositories). Readbacks of Actions permissions, code security, and `security_and_analysis` need the owner's token.

GitHub adds `require_extra_approval_for_unattributed_changes: true` and `allowed_merge_methods` to a ruleset's
pull-request rule on its own; they are expected in a readback, not drift. No pull request here is opened under a Copilot
app identity, so required approvals stay 0.

When the maintainer applies a row, set its tier to "Enforced" with the date, and update the matching row of the
enforcement register in `.agents/knowledge/git-workflow.md`.
